## 💡 Fitur Sistem v1.0
* **Portal Publik:** Beranda kegiatan, profil & sejarah desa, struktur organisasi (SOTK), galeri foto & video, serta form kritik/saran.
* **Layanan Mandiri Warga:** Blanko pengurusan administrasi surat desa.
* **Database SQL:** Skema database relasional `desa_kupal.sql` mencakup tabel kependudukan, pengumuman, dan berita.
